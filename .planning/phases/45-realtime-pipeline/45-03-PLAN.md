<task type="auto">
  <name>Task 1: Add processing count badge to sidebar Documents link</name>
  <files>frontend/src/components/sidebar.tsx, frontend/src/lib/hooks.ts</files>
  <action>
  1. Create a small helper hook `useProcessingCount` in `hooks.ts` that:
     - Calls `useDocuments({ limit: 500, offset: 0 })` (same as documents page).
     - Returns the count of documents with pipeline_status in ['uploaded', 'ocr', 'classifying', 'analyzing'].
     - Returns 0 when data is loading or unavailable.

  2. In `frontend/src/components/sidebar.tsx` (or wherever the sidebar nav is defined):
     - Import and call `useProcessingCount()`.
     - Next to the "Documents" nav link, render a small badge showing the count when > 0.
     - Badge styling: `bg-amber-500/20 text-amber-400 text-xs font-medium px-1.5 py-0.5 rounded-full` — subtle amber to indicate activity without alarm.
     - Add a small pulsing dot animation: `animate-pulse` on a 6px circle next to the count.
     - When count is 0, render nothing (no badge).

  Do NOT add processing indicators to other nav items or the header — keep it focused on the Documents link where processing happens.
  </action>
  <verify>Read sidebar component and confirm badge renders with processing count. Build succeeds.</verify>
  <done>Sidebar Documents link shows amber badge with processing count and pulse animation when documents are processing. Hidden when idle.</done>
</task>

<task type="auto">
  <name>Task 2: Auto-invalidate analysis queries on pipeline completion</name>
  <files>frontend/src/hooks/use-document-notifications.ts</files>
  <action>
  Enhance the `useDocumentNotifications` hook to also invalidate relevant TanStack Query caches when documents complete:

  1. Import `useQueryClient` from `@tanstack/react-query`.
  2. When a document transitions to `complete`:
     - Call `queryClient.invalidateQueries({ queryKey: ['document-analysis', documentId] })` to refresh analysis data.
     - Call `queryClient.invalidateQueries({ queryKey: ['analytics'] })` to update dashboard analytics if the analytics page is mounted.
  3. When a document transitions to `failed`:
     - Call `queryClient.invalidateQueries({ queryKey: ['documents'] })` to refresh the document list (status update).

  This ensures that all visible data automatically reflects pipeline completion without manual refresh.
  </action>
  <verify>Read the updated hook. Confirm queryClient.invalidateQueries calls for complete and failed transitions. Build succeeds.</verify>
  <done>Pipeline completion auto-refreshes analysis data and analytics. Failed status auto-refreshes document list.</done>
</task>

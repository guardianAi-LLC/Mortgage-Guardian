  <files>frontend/src/app/dashboard/documents/page.tsx</files>
  <action>
Add a batch action bar that appears when selectedIds.size > 0:

1. **Batch action bar**: Fixed or sticky bar above the table (below filters) with:
   - "X documents selected" text
   - "Delete Selected" button (red/destructive variant)
   - "Re-analyze Selected" button (blue/primary variant)
   - "Clear Selection" link/button

2. **Delete confirmation**: Use the existing ui/dialog.tsx to show a confirmation dialog:
   - Title: "Delete X Documents"
   - Body: "This action cannot be undone. The selected documents and their analysis results will be permanently deleted."
   - Actions: Cancel / Delete (destructive)
   - On confirm: Call useDeleteDocument().mutateAsync() sequentially for each selected ID. Show progress. Clear selection on complete. Invalidate queries.

3. **Re-analyze**: Call useRetryDocument().mutateAsync() sequentially for each selected ID. Show a brief loading state. Clear selection on complete. Invalidate queries.

4. Handle partial failures gracefully: if some operations fail, show count of successes/failures, don't clear selection for failed items.

Do NOT add toast notifications — that's a later phase (45). Use inline status text in the batch bar for feedback.
  </action>

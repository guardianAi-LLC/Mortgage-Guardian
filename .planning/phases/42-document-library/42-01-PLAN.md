  <action>
Add a mapDocument() helper in hooks.ts (same pattern as mapCase) to transform snake_case fields from Supabase:
- document_id → documentId (or keep if already camelCase)
- file_name → fileName
- document_type → documentType
- analysis_report → analysisReport
- created_at → createdAt
- pipeline_status → pipelineStatus

Add these hooks to hooks.ts:

1. `useDocuments(params?: { limit?: number; offset?: number })` — calls api.documents.list(), unwraps `res.documents ?? res`, maps each through mapDocument(). Returns TanStack Query result with Document[].

2. `useDocument(documentId: string)` — calls api.documents.get(), maps through mapDocument(). enabled: !!documentId.

3. `useDeleteDocument()` — mutation calling api.documents.delete() (note: api.ts has no delete method yet — add it as `delete: (token, id) => fetchWithAuth(\`/documents/${id}\`, token, { method: 'DELETE' })`). Invalidates ['documents'] query on success.

4. `useRetryDocument()` — mutation calling api.documents.retry(). Invalidates ['documents'] and ['document-status', documentId] on success.

Also add `api.documents.delete` to api.ts if missing (check first — the backend DELETE /v1/documents/:documentId exists).

Do NOT modify existing hooks — only add new ones below the existing document hooks section.

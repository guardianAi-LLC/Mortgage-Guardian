<task type="auto">
  <name>Task 1: Create structuredReasoningConfig.js</name>
  <files>backend-express/config/structuredReasoningConfig.js</files>
  <action>
Create a shared structured reasoning configuration following the same declarative pattern as evidenceEnrichmentConfig.js. Include:

1. REASONING_FIELDS — base reasoning fields for every finding:
   - reasoningSteps: array of strings (each step in the chain of thought), default []
   - confidence: number 0-1, default null
   - confidenceLevel: string enum (high/medium/low), default null
   - confidenceExplanation: string explaining why this confidence level, default null

2. CONFIDENCE_SCALE — define the 3-tier confidence scale:
   - high (>=0.85): "Clear documentary evidence with specific values, dates, or amounts that directly demonstrate the finding"
   - medium (0.5-0.84): "Evidence supports the finding but requires interpretation, inference, or has minor ambiguity"
   - low (<0.5): "Finding is possible but evidence is indirect, circumstantial, or insufficient for definitive conclusion"

3. REASONING_PROMPT_INSTRUCTIONS — reusable prompt fragments:
   - ANOMALY_REASONING_INSTRUCTION: instruct Claude to provide step-by-step reasoning for each anomaly (what was expected, what was found, why it's anomalous) plus a 0-1 confidence score
   - DISCREPANCY_REASONING_INSTRUCTION: instruct Claude to show reasoning chain for each discrepancy (value in doc A, value in doc B, why they conflict, regulatory significance) plus confidence
   - VIOLATION_REASONING_INSTRUCTION: instruct Claude to provide legal reasoning chain (statute requirement, observed behavior, how behavior violates statute, legal consequence) plus confidence
   - CLASSIFICATION_REASONING_INSTRUCTION: instruct Claude to explain document feature analysis, taxonomy matching process, and confidence rationale
   - GENERAL_REASONING_INSTRUCTION: broad instruction to show work, avoid unsupported conclusions, and assign confidence based on evidence strength

4. Helper function getConfidenceLevel(score) that maps 0-1 score to high/medium/low using the thresholds above.

Use JSDoc comments. No business logic beyond getConfidenceLevel — this is config data. Export all constants and the helper.

  <name>Task 1: Update Joi schemas for reasoning/confidence response fields</name>
  <files>backend-express/schemas/analysisReportSchema.js, backend-express/schemas/complianceReportSchema.js, backend-express/schemas/consolidatedReportSchema.js, backend-express/schemas/crossDocumentAnalysisSchema.js</files>
  <action>
Update each schema to include the new reasoning fields as optional:

1. analysisReportSchema.js — Add to anomaly objects:
   - reasoningSteps: Joi.array().items(Joi.string()).optional().default([])
   - confidence: Joi.number().min(0).max(1).optional().allow(null).default(null)
   - confidenceLevel: Joi.string().valid('high', 'medium', 'low').optional().allow(null).default(null)

2. crossDocumentAnalysisSchema.js — Add to discrepancy objects:
   - reasoningSteps: Joi.array().items(Joi.string()).optional().default([])
   - confidence: Joi.number().min(0).max(1).optional().allow(null).default(null)
   - confidenceLevel: Joi.string().valid('high', 'medium', 'low').optional().allow(null).default(null)

3. complianceReportSchema.js — Add to violation objects:
   - reasoningSteps: Joi.array().items(Joi.string()).optional().default([])
   - confidence: Joi.number().min(0).max(1).optional().allow(null).default(null)
   - confidenceLevel: Joi.string().valid('high', 'medium', 'low').optional().allow(null).default(null)

4. consolidatedReportSchema.js — Add reasoning fields to any finding/violation sub-objects that mirror the above schemas.

All new fields MUST be .optional() with defaults — schemas must still validate responses that don't include reasoning (backward compat with any cached/older data).

<task type="auto">
  <name>Task 1: Update disputeLetterService to leverage enriched evidence</name>
  <files>backend-express/services/disputeLetterService.js, backend-express/__tests__/services/disputeLetterService.test.js</files>
  <action>
Modify the dispute letter service to include specific document citations, page references, and quoted evidence in the letter generation.

**_extractViolations() changes:**
1. When extracting violations from the consolidated report, include the enriched fields:
   - `sourceDocuments`: the document names/types that triggered the violation
   - `quotedEvidence`: collected from supportingFindings[].quotedText
   - `pageReferences`: from the violation's pageReferences array
   - Format for the prompt: each violation should include a line like "Source: [DocumentName], page [X]. Evidence: '[quotedText]'"

**_extractFindings() changes:**
2. When extracting anomalies and discrepancies:
   - Include pageReference and quotedText from each anomaly
   - Include per-document evidence from each discrepancy
   - Format for the prompt: "[DocumentName, p.X]: [quotedText]" for each finding

**Claude prompt changes:**
3. Update the letter generation prompt to instruct Claude:
   - "Reference specific documents by name and page number in your letter"
   - "Quote exact values and text from the source documents to support each claim"
   - "Structure evidence citations in the format: (See [Document Name], page [X], stating '[quoted text]')"
   - "Every factual claim in the letter must be supported by a specific citation"
   - Include the enriched evidence data in the prompt context so Claude can reference it

4. In the prompt data section, format the evidence clearly:
   - Group findings by document
   - List page references alongside each finding
   - Include quoted text for each claim

**Backward compatibility:**
- If enriched evidence fields are null/empty, fall back to current behavior (findings without citations)
- The letter should still generate successfully even without enriched evidence

**Test updates:**
5. Update disputeLetterService tests:
   - Provide mock consolidated report with enriched evidence
   - Verify the prompt sent to Claude includes document names, page numbers, and quoted text
   - Verify letter generation works with un-enriched data (backward compat)
   - Update mock Claude responses to include citation-style references

  <name>Task 1: Enrich complianceRuleEngine violations with source document links</name>
  <files>backend-express/services/complianceRuleEngine.js</files>
  <action>
Modify the compliance rule engine to trace violations back to their source documents and supporting findings.

**When the rule engine generates a violation from a finding (anomaly or discrepancy):**
1. Import `VIOLATION_EVIDENCE_FIELDS` from `../config/evidenceEnrichmentConfig.js`
2. When creating a violation object, add these new fields:
   - `sourceDocuments`: Array of { id, name, type } — pulled from the enriched anomaly's sourceDocument or the discrepancy's documentA/documentB metadata. If a violation is triggered by multiple anomalies across different documents, collect all unique source documents.
   - `supportingFindings`: Array of { findingId, findingType, quotedText } — reference the anomaly ID or discrepancy ID that triggered this violation, along with its quotedText evidence. findingType is "anomaly" or "discrepancy".
   - `pageReferences`: Array of { documentId, documentName, pageNumber } — collected from the enriched evidence on the triggering findings. Filter out entries where pageNumber is null.

**Implementation approach:**
3. In each rule evaluation function (where violations are created from matched findings):
   - Track which findings triggered the violation (they should be available as the input data)
   - Extract sourceDocument, pageReference, and quotedText from those findings (these fields were added in Plans 01 and 02)
   - Attach as new fields on the violation object
4. If the triggering finding doesn't have enriched evidence (backward compat with old data), default:
   - sourceDocuments: [] (empty array)
   - supportingFindings: [] (empty array)
   - pageReferences: [] (empty array)

**What to avoid:**
- Do NOT change which rules trigger violations or how severity is determined
- Do NOT modify the statute taxonomy or rule definitions
- Do NOT change the violation's core fields (statuteId, citation, description, etc.)
- Keep it simple — just thread through the evidence that's already on the input findings

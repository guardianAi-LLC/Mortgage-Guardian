<task type="auto">
  <name>Task 2: Wire notification preferences into toast system</name>
  <files>frontend/src/hooks/use-document-notifications.ts</files>
  <action>
  Create a small helper to read notification prefs:

  ```ts
  function getNotificationPrefs(): { complete: boolean; findings: boolean; errors: boolean } {
    if (typeof window === 'undefined') return { complete: true, findings: true, errors: true }
    try {
      const raw = localStorage.getItem('mg_notification_prefs')
      return raw ? JSON.parse(raw) : { complete: true, findings: true, errors: true }
    } catch {
      return { complete: true, findings: true, errors: true }
    }
  }
  ```

  In useDocumentNotifications, before firing toasts:
  - Read prefs via getNotificationPrefs()
  - Only fire toast.success on complete if prefs.complete is true
  - Only fire toast.error on failed if prefs.errors is true
  - Keep query invalidation regardless of prefs (data should still refresh)

  Put the helper in the same file or export from a shared location.

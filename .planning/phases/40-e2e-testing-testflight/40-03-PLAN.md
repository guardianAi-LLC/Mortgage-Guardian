     - Verify Info.plist CFBundleShortVersionString and CFBundleVersion match project settings
  
  2. **Archive build test:**
     ```bash
     xcodebuild archive -project MortgageGuardian.xcodeproj \
       -scheme MortgageGuardian \
       -archivePath /tmp/MortgageGuardian.xcarchive \
       -destination 'generic/platform=iOS' \
       CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
       SKIP_INSTALL=NO 2>&1 | tail -20
     ```

     If it fails due to signing, that's expected in dev — document it.

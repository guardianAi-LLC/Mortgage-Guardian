<task type="auto">
  <name>Task 1: Create reportFormattersService module</name>
  <files>backend-express/services/reportFormattersService.js</files>
  <action>
Create a stateless module exporting pure formatter functions. NO class, NO singleton — these are pure utilities. Export an object with these functions:

1. `formatCitation({ documentName, pageNumber, quotedText })` — returns string like `[loan-statement-jan.pdf, p.2]: "exact quoted text"`. If `documentName` missing returns `null`. If `pageNumber` missing, omit ", p.X". If `quotedText` missing, omit `: "..."`. Truncate quotedText to 200 chars with `...` if longer.

2. `formatReasoningChain(reasoningSteps, { maxSteps = 3, joiner = ' → ' } = {})` — given an array of step strings, returns joined chain. Returns `null` if input is empty or not an array. Truncates each step to 120 chars. Joins first `maxSteps` steps; if truncated, appends ` (+N more)`.

3. `formatConfidenceLabel(confidence, confidenceLevel)` — returns human-readable label like `"High (0.92)"` / `"Medium (0.71)"` / `"Low (0.34)"`. If `confidenceLevel` provided, capitalize and use it; otherwise derive via `getConfidenceLevel` from `structuredReasoningConfig`. If both missing returns `null`. Confidence shown to 2 decimals.

4. `buildEvidenceFootnote({ findingId, citations, reasoningChain, confidenceLabel })` — assembles a structured footnote object: `{ findingId, citations: string[], reasoning: string|null, confidence: string|null }`. Filters out null/empty citations. Returns `null` if no citations and no reasoning.

5. `formatExecutiveSummaryLine(finding)` — given a finding (anomaly/discrepancy/violation shape), returns a one-line summary like `"[critical] RESPA §6 violation: servicer failed to acknowledge QWR (Source: response-letter.pdf, p.1; confidence: high)"`. Gracefully degrades: if no source/confidence, omits parenthetical.

Import `getConfidenceLevel` from `../config/structuredReasoningConfig`. No external deps beyond Node stdlib. Add JSDoc on each function with example input/output. Use the same module-style export pattern as `evidenceEnrichmentConfig.js` (`module.exports = { ... }`).

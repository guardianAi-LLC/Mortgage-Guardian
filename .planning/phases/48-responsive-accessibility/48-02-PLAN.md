**Key insight:** The app uses @base-ui/react Table components. Tables have 5-6 columns each. On mobile (< 768px), hide non-essential columns (borrower, servicer, created date) and keep essential ones (name, status, primary metric). Wrap all tables in `overflow-x-auto` as a safety net.

**Established patterns:** Tailwind responsive prefixes (md:table-cell with hidden default).
</context>

<task type="auto">
  <name>Task 1: Case table responsive columns</name>
  <files>frontend/src/components/case-table.tsx</files>
  <action>
1. Wrap the `<Table>` in a `<div className="overflow-x-auto">` container.

2. Hide non-essential columns on mobile using `hidden md:table-cell` on both TableHead and TableCell:
   - KEEP visible always: Case Name, Status (these are essential)
   - HIDE on mobile: Borrower (`hidden md:table-cell`), Servicer (`hidden md:table-cell`), Documents count (`hidden sm:table-cell`), Created (`hidden lg:table-cell`)

3. Apply the same responsive classes to LoadingRows skeleton cells to match.

4. Make TableRow clickable rows keyboard accessible: add `tabIndex={0}` and `onKeyDown={(e) => { if (e.key === 'Enter') router.push(...) }}` alongside the existing onClick. Add `role="link"` to indicate it navigates.
  </action>
  <verify>Run `cd frontend && npx next build` — build succeeds.</verify>

**Current state:**
- `<html lang="en" className="dark">` hard-coded in layout.tsx
- CSS variables in globals.css set dark values on :root
- Components use both `dark:` prefixed Tailwind classes AND direct gray-950/gray-800 colors
- No next-themes installed
- @base-ui/react components use dark: prefix classes in some places

**Key risk:** Many components use hard-coded dark colors (bg-gray-950, text-gray-400, border-gray-800) instead of semantic CSS variables. Light mode needs either:
  a) CSS variables for all semantic colors (background, foreground, border, muted) — preferred
  b) Or adding dark: prefixes everywhere — tedious and fragile

Approach: Define light mode CSS variables on :root and dark mode on .dark class. Update globals.css. Most components already reference Tailwind semantic colors (bg-background, text-foreground) via CSS variables — verify and fix any that use hard-coded gray values.
</context>

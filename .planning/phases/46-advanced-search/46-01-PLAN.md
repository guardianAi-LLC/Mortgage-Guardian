  Create a `GlobalSearch` component:

  1. **Search input**: Debounced (300ms) text input with Search icon (lucide-react), styled as dark input matching sidebar theme.
     - Keyboard shortcut: Cmd+K (Mac) or Ctrl+K opens/focuses the search
     - Escape key closes the dropdown

  2. **Data fetching**: Import and use `useCases()` and `useDocuments({ limit: 500, offset: 0 })` from `@/lib/hooks`.
     - Filter client-side by matching query against:
       - Cases: caseName, borrowerName, servicerName, loanNumber
       - Documents: file_name, document_type

  3. **Results dropdown** (absolute positioned below input, shown when query length >= 2):
     - Two sections: "Cases" and "Documents" with section headers
     - Max 5 results per section
     - Each result is a Link:
       - Case: `/dashboard/cases/{id}` — show caseName + borrowerName + status badge
       - Document: `/dashboard/documents/{document_id}` — show file_name + document_type + status badge
     - If no results: "No results for '{query}'"
     - Dropdown styling: bg-gray-900 border border-gray-700 rounded-lg shadow-xl z-50 max-h-[400px] overflow-y-auto
     - Click outside closes dropdown (useEffect with document click listener)

  4. **Loading state**: Show small spinner while data is loading.

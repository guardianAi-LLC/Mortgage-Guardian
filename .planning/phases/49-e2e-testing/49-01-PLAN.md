<task type="auto">
  <name>Task 1: Install Playwright and create configuration</name>
  <files>frontend/package.json, frontend/playwright.config.ts, frontend/e2e/helpers/auth.ts</files>
  <action>
Install Playwright and Clerk testing helper:
```
cd frontend && npm install -D @playwright/test @clerk/testing
npx playwright install chromium firefox webkit
```

Create `frontend/playwright.config.ts`:
- baseURL: `http://localhost:3000`
- testDir: `./e2e`
- webServer: `npm run dev` with port 3000 (reuseExistingServer: true in CI)
- Projects: chromium (default), firefox, webkit
- Reporter: html + list
- retries: 1 in CI, 0 locally
- use: screenshot on failure, trace on first retry
- timeout: 30s per test, 10s per action

Create `frontend/e2e/helpers/auth.ts`:
- Export `setupAuth(page)` that uses `@clerk/testing` `setupClerkTestingToken()` — this injects a test token via Clerk's testing mode, bypassing real OAuth. Requires `CLERK_TESTING_TOKEN` or Clerk's test mode env vars.
- Alternative: If @clerk/testing doesn't support current Clerk version, create a `storageState` approach — sign in once via Clerk test API and save auth state to `frontend/.auth/user.json` (gitignored).

Create `frontend/e2e/helpers/test-utils.ts`:
- Export `test` and `expect` from @playwright/test with extended fixtures if needed
- Export common selectors and page helpers (e.g., `waitForDashboard`, `navigateTo`)

Do NOT use @clerk/testing's `clerkSetup` global setup if it requires a real Clerk dev instance — instead use `setupClerkTestingToken` per-test which works with NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY in test mode.
  </action>
  <verify>
```bash
cd frontend && npx playwright --version
ls frontend/playwright.config.ts frontend/e2e/helpers/auth.ts frontend/e2e/helpers/test-utils.ts
```
  </verify>
  <done>Playwright installed, config created with 3 browser projects, auth helper exists, helpers directory structured</done>
</task>

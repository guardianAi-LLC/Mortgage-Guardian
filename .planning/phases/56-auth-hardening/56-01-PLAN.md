Add CSRF defense-in-depth via an Origin/Referer middleware on state-changing routes, with bearer-bypass so iOS and server-to-server clients are unaffected. Plaid webhook explicitly exempt.

Output: `backend-express/middleware/csrfOriginGuard.js`, mounted in `backend-express/server.js` (or app entry), exempting the Plaid webhook. Test coverage proving accept/reject behavior on all state-changing routes.

<task type="auto">
  <name>Task 1: Implement csrfOriginGuard middleware</name>
  <files>backend-express/middleware/csrfOriginGuard.js</files>
  <action>
Export `csrfOriginGuard(options)` returning Express middleware. Logic:
- If method is GET/HEAD/OPTIONS → next().
- If `Authorization: Bearer …` header is present → next() (bearer clients are CSRF-immune; iOS / server-to-server unaffected).
- If req path matches `options.exemptPaths` (array of exact strings or RegExp) → next(). Used to exempt `/v1/plaid/webhook`.
- Otherwise: read `Origin` header (fallback to `Referer` origin). If missing OR not in `options.allowedOrigins` (parsed from `ALLOWED_ORIGINS` env at construction) → respond 403 JSON `{ error: 'csrf_origin_mismatch', message: 'Origin header missing or not allowed' }` and log via `createLogger('security').warn('csrf_origin_rejected', { method, path, origin, referer, requestId })`.
- If origin matches → next().

Do NOT use `csurf` (deprecated). Do NOT add cookies. Helper must be pure (no global state beyond the constructor's allowed-origins set).

Export shape: `module.exports = { csrfOriginGuard };`
  </action>
  <verify>`node -e "require('./backend-express/middleware/csrfOriginGuard.js')"` loads without error; `npm --prefix backend-express run lint -- middleware/csrfOriginGuard.js` clean.</verify>
  <done>Middleware exported; rejects missing/mismatched Origin on state-changing non-bearer requests; bypasses on bearer; bypasses on exempt paths; bypasses GET/HEAD/OPTIONS.</done>

<task type="auto">
  <name>Task 2: Mount middleware in app, exempt Plaid webhook</name>
  <files>backend-express/server.js</files>
  <action>
Locate the Express app setup (after `helmet()`, after CORS, before route mounts). Insert:
```js
const { csrfOriginGuard } = require('./middleware/csrfOriginGuard');
app.use(csrfOriginGuard({
  allowedOrigins: (process.env.ALLOWED_ORIGINS || '').split(',').map(s => s.trim()).filter(Boolean),
  exemptPaths: ['/v1/plaid/webhook'],
}));
```
Place it BEFORE route mounting so all state-changing routes pass through it. The middleware itself short-circuits non-mutating verbs, so GET routes are unaffected. Do NOT touch `routes/plaid.js` or any route file — the exemption is path-based at the middleware level.

If `server.js` doesn't exist, find the actual app entry (`index.js`, `app.js`). Use `grep -l "helmet" backend-express/*.js` to locate.

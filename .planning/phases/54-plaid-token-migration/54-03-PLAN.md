<objective>
Remove all Plaid access_token handling from the Next.js frontend. The client only ever knows `item_id` values returned by `GET /v1/plaid/items` and a one-time `public_token` during link flow.

Purpose: Close the browser-side attack surface — localStorage XSS exfiltration of bank credentials is no longer possible because the credential isn't there.
Output: Updated `lib/api.ts`, `use-plaid-link.ts`, `bank-accounts/page.tsx`, `lib/types.ts`. Removed `mg_plaid_access_tokens` localStorage usage. One-time cleanup that purges the legacy key on first load.
</objective>

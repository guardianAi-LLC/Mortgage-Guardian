  <files>backend-express/scripts/clamav-health-check.js, backend-express/scripts/README.md</files>
  <action>
1. Create `backend-express/scripts/clamav-health-check.js`:
   - Loads `dotenv` from `backend-express/.env` (matches the Phase 54 backfill pattern).
   - Reads `CLAMAV_HOST` / `CLAMAV_PORT` from env; fails with exit 2 if missing.
   - Uses `clamscan` npm to:
     a. PING — exit 1 with `unreachable` if no response within `CLAMAV_TIMEOUT_MS`.
     b. Version query — log clamd engine version + signature DB date.
     c. Sig age check — if `engineVersion.dbAge > 24h`, log a warning. If `> 7d`, exit 1.
     d. EICAR live-fire — same test as 55-01-Task-3 step 3 but scripted. Must detect.
   - Exit 0 only when reachable + sig age <24h + EICAR detected.
   - Log only counts and timestamps. NEVER the buffer or the EICAR string.

2. Update `backend-express/scripts/README.md`:
   - Add a new section `## clamav-health-check.js  (Phase 55-04)` patterned on the Phase 54 backfill section.
   - Document required env, usage, exit codes, when to run (post-deploy, in oncall paging, ad-hoc).
   - Cross-link to the runbook section being added in Task 2.

Do NOT:
- Make the script perform any scan against real user files. Smoke test only.
- Print signature update logs verbatim — they're chatty and a future log scraper might capture them in unexpected places.
  </action>

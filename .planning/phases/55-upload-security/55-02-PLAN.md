<feature>
  <name>malwareScanService.scanBuffer(buffer)</name>
  <files>backend-express/services/malwareScanService.js, backend-express/__tests__/services/malwareScanService.test.js</files>
  <behavior>
The function takes a Node `Buffer` and resolves to a verdict object, or rejects with `MalwareScanError`.

Contract:
- `scanBuffer(Buffer): Promise<{ scanned: true, clean: boolean, threats: string[], engine: 'clamav' }>`
- Throws `MalwareScanError` (custom subclass of `Error` exported alongside) on:
  - Connection refused / timeout / DNS failure to clamd
  - Malformed clamd response
  - Any other infrastructure failure

Cases the test file must cover (RED phase writes ALL of these first):

| # | Input | Expected |
|---|-------|----------|
| 1 | Buffer of the EICAR test string | resolves; `clean === false`; `threats` non-empty array containing a string matching `/EICAR/i`; `scanned === true`; `engine === 'clamav'` |
| 2 | Buffer of a small known-clean payload (e.g., `Buffer.from('clean pdf-like bytes')`) | resolves; `clean === true`; `threats === []`; `scanned === true` |
| 3 | `CLAMAV_HOST` pointed at an unreachable address (`127.0.0.1:1` works for connection-refused) | rejects with `MalwareScanError`; error message includes `connection` or similar; does NOT resolve as clean |
| 4 | `buffer` arg is not a Buffer (e.g., string) | rejects synchronously with a `TypeError` before any network call |
| 5 | Caller passes empty Buffer (0 bytes) | rejects with `MalwareScanError` (clamd treats empty INSTREAM as protocol error and we don't want to leak that as "clean") |

Implementation guidance (GREEN phase, do NOT write before tests fail):
- Require `clamscan` npm. Initialize a singleton `NodeClam` via `new NodeClam().init({ clamdscan: { host, port, timeout, bypassTest: false, active: true }, preference: 'clamdscan' })` lazily on first call.
- Wrap `clamdscan.scanStream(stream)` — convert the buffer to a `Readable` stream via `Readable.from(buffer)`.
- Map `{ isInfected, viruses }` to the verdict object.
- Catch ALL errors from clamscan and rethrow as `MalwareScanError(originalError.message, { cause: originalError })`. Log via `createLogger('malware-scan')` at error level WITHOUT logging buffer content.
  </behavior>
  <implementation>
Test framework: Jest already configured. Use `__tests__/services/malwareScanService.test.js`.

For Cases 1, 2: tests require live clamd. Gate them with `describe.skip` if `process.env.CLAMAV_HOST` is unset, so CI without a clamd sidecar still passes the rest of the suite. CI with the Railway sidecar reachable can run them; document this in the test file's top comment.

For Cases 3, 4, 5: pure unit tests — no live clamd needed. They override `CLAMAV_HOST` per-test or test pre-clamd-call argument validation.

**Create bank-accounts/page.tsx:**
- PageHeader: title="Bank Accounts", description="Link and manage your bank accounts"
- PlaidLinkButton at top-right area (within a flex row with the header or as action button)
- On PlaidLinkButton success: call useExchangeToken mutation with public_token, store returned access_token in localStorage array (key: "plaid_access_tokens"), refetch accounts
- Linked accounts section:
  - Read access_tokens from localStorage on mount
  - For each access_token, use usePlaidAccounts to fetch accounts
  - Display as cards (not table — accounts are visual): institution name, account name, type, mask (last 4), balance
  - Card styling: bg-gray-900 border border-gray-800 rounded-xl p-4
  - Account type badge (checking, savings, credit, etc.)
  - Balance display: current balance formatted as currency
- Unlink button per item (not per account — one item = one institution):
  - Confirmation dialog before unlinking
  - Calls useDeletePlaidItem mutation
  - Removes access_token from localStorage
  - Refetches account list
- Empty state when no accounts linked: EmptyState with Landmark icon, "No bank accounts linked", "Link a bank account to verify mortgage payments"
- Loading skeleton while fetching accounts
- Error handling for failed account fetches (access_token expired → show re-link prompt)

**localStorage helper:**
- getPlaidAccessTokens(): string[] — parse JSON array from localStorage
- addPlaidAccessToken(token: string): void — append and save
- removePlaidAccessToken(token: string): void — filter out and save

Put these helpers in a small utility at top of page file or in a separate file if >15 lines.

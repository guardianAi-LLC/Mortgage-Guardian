**Backend Plaid endpoints (already exist, proxied via /api/v1/plaid/*):**
- POST /v1/plaid/link_token — create Link token (body: { user_id, client_name?, redirect_uri?, access_token?, products? })
- POST /v1/plaid/exchange_token — exchange public token (body: { public_token, institution? })
- POST /v1/plaid/accounts — get accounts (body: { access_token })
- POST /v1/plaid/transactions — get transactions (body: { access_token, start_date?, end_date?, count?, offset? })
- POST /v1/plaid/item — get item info (body: { access_token })
- DELETE /v1/plaid/item — delete item (body: { access_token })
- POST /v1/plaid/sandbox_public_token — create sandbox token (body: { institution_id?, products? })

**Established patterns:**
- fetchWithAuth() in api.ts for all API calls
- React Query hooks in hooks.ts with useAuth() for token
- mapCase() for snake_case→camelCase transforms
- kebab-case component files, camelCase hooks

  <files>frontend/package.json, frontend/src/lib/api.ts, frontend/src/lib/types.ts</files>
  <action>
**Install:**
- `cd frontend && npm install react-plaid-link`

**Add Plaid types to types.ts:**
- PlaidAccount: { account_id, name, official_name?, type, subtype, mask?, balances: { available, current, limit?, currency } }
- PlaidTransaction: { transaction_id, account_id, amount, date, name, merchant_name?, category?, pending }
- PlaidItem: { item_id, institution_id, institution_name?, consent_expiration_time?, available_products?, billed_products? }
- PlaidLinkResult: { linkToken: string, expiration: string }
- PlaidExchangeResult: { access_token: string, item_id: string }

**Add api.plaid methods to api.ts:**
- createLinkToken(token, data: { userId: string }) — POST /plaid/link_token with body { user_id: data.userId }
- exchangeToken(token, data: { publicToken: string, institution?: object }) — POST /plaid/exchange_token with body { public_token: data.publicToken, institution: data.institution }
- getAccounts(token, accessToken: string) — POST /plaid/accounts with body { access_token: accessToken }
- getTransactions(token, data: { accessToken: string, startDate?: string, endDate?: string }) — POST /plaid/transactions with body { access_token, start_date, end_date }
- getItem(token, accessToken: string) — POST /plaid/item with body { access_token: accessToken }
- deleteItem(token, accessToken: string) — DELETE /plaid/item with body { access_token: accessToken }

Note: Backend Plaid routes use POST with body params (not GET with path params) for access_token security. Match this pattern exactly.

- usePlaidAccounts(accessToken?: string) — React Query hook wrapping api.plaid.getAccounts, enabled only when accessToken provided
- usePlaidTransactions(accessToken?: string, dateRange?: { startDate: string, endDate: string }) — React Query hook wrapping api.plaid.getTransactions
- usePlaidItem(accessToken?: string) — React Query hook wrapping api.plaid.getItem
- useDeletePlaidItem() — useMutation wrapping api.plaid.deleteItem
- useLinkToken() — useMutation wrapping api.plaid.createLinkToken
- useExchangeToken() — useMutation wrapping api.plaid.exchangeToken

All hooks follow established pattern: useAuth() for token, useQuery/useMutation from @tanstack/react-query.

**Create plaid-link-button.tsx component:**
- Props: { onSuccess: (publicToken: string, metadata: PlaidLinkOnSuccessMetadata) => void, onExit?: () => void, accessToken?: string (for update mode), className?: string, children?: ReactNode }
- Uses useLinkToken mutation to create link token on mount/click
- Uses usePlaidLink from react-plaid-link to open Plaid Link modal
- Button renders with "Link Bank Account" default text
- Loading state while creating link token
- Error state if link token creation fails
- Follow dark theme: bg-blue-600 hover:bg-blue-700 text-white rounded-lg

Note: react-plaid-link's usePlaidLink expects { token, onSuccess, onExit } config. Create the link token first, then pass it. The hook returns { open, ready } — call open() when ready.
